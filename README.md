# Fitness Landing Page

Slicing landing page Fitness sesuai desain, dibangun dengan HTML, CSS, dan JavaScript native (tanpa framework).

## Struktur Folder
- `index.html` — markup utama halaman
- `css/style.css` — seluruh styling, termasuk responsive (mobile, tablet, desktop)
- `js/main.js` — interaksi (nav toggle mobile, smooth scroll, tombol play video)
- `assets/images` — gambar (hero, trainer, testimonial, dll)
- `assets/icons` — icon SVG (email, phone, location)

## Cara Menjalankan
1. Clone repository ini
2. Buka `index.html` langsung di browser, atau gunakan Live Server (VSCode extension)

## Fitur
- Fully responsive: mobile, tablet, desktop
- Hamburger menu untuk navigasi mobile
- Smooth scroll antar section
- Struktur folder rapi & mudah dikembangkan

## Teknologi
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (Vanilla)
